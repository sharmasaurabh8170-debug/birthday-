# Birthday Surprise 🎂

A birthday surprise website built using React and Vite.

## Technologies Used

- React
- Vite
- JavaScript
- CSS

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the website

Open the local URL displayed in your terminal.

## Development

This project uses Vite for fast development and Hot Module Replacement (HMR).
